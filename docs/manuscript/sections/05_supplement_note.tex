\section{Supplementary materials}
\label{sec:supplement}

Supplementary figures and tables are generated by the analysis pipeline in \texttt{figures/manuscript/appendix/}, including:
vital-sign hazard ratios from the M4 model;
sequential attenuation for ED workflow variables;
disposition-stratified M4 forests;
within-acuity heatmaps for age, sex, diagnosis, and language;
IPTW balance and weighted Cox results;
and continuous-year Cox estimates.
